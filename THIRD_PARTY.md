# Sources and dependencies

The plugin's skills, prompt templates, Node adapters, and native bridges are original implementations. No existing game's assets, scripts, configuration, story, or acceptance fixtures are included.

- Runtime dependency: [`@modelcontextprotocol/sdk`](https://github.com/modelcontextprotocol/typescript-sdk), MIT. Exact dependency versions and transitive dependencies are recorded in `package-lock.json`; their license files remain in their installed packages.
- External applications: [Godot](https://godotengine.org/) and [Pixelorama](https://pixelorama.org/). Install them separately. Their application binaries and personal settings are not part of this source package.
- Workflow inspiration: [Academic Research Skills](https://github.com/Imbad0202/academic-research-skills) and its [Codex distribution](https://github.com/Imbad0202/academic-research-skills-codex), particularly composable capabilities, discussion summaries, and review/revision handoffs. The academic workflows and their platform-specific hooks are not vendored.

The neutral integration lab uses original diagnostic geometry. The showcase contains AI-assisted pixel artwork and a user-supplied portrait animation. These examples illustrate workflows rather than prescribing a game genre or art style.
