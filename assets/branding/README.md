# PixWeft logo

A two-line pixel wordmark developed from the supplied sketches. The current lower-case w has three upright stems and two mirrored rounded bowls. Its ink width is 55 native pixels, reduced from 71. The f and t retain their shared crossbar.

![PixWeft](pixweft-logo-2x.png)

- [Native-size transparent PNG](pixweft-logo.png): 192 x 144 pixels.
- [README-size transparent PNG](pixweft-logo-2x.png): 384 x 288 pixels, exact 2x nearest-neighbor enlargement.
- [Editable Pixelorama source](pixweft-logo.pxo): one frame and one pixel layer.
- [Generation prompts and revision notes](prompt.md).
- [Source and export measurements](manifest.json).

The initial artwork was generated with Codex's built-in image tool and refined in Pixelorama. The latest edit starts from the user's revised 2x PNG, retained under reference/. That input exactly follows a 2x pixel grid, so native import preserved every logical pixel. Only the w and its owned outline were replaced through native Pixelorama pixel operations. All pixels outside that region match the user's input, including the edited i.

The source has portable export metadata. A fresh native reopen/export matched the delivered PNG. The final logo was inspected on light and dark backgrounds. These colors and dimensions apply to this logo, not to plugin-wide game settings.
