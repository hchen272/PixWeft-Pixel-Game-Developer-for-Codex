# Neutral integration lab

This is a small executable fixture for bridge verification. Its procedural
rectangles are test geometry, not a recommended art style or asset pipeline.
It establishes no genre, projection, character size, palette, or map system
defaults for user projects.

Run `project.godot` in Godot 4.6.3. Arrow keys move, Space interacts near the
right-hand target, and R restarts. The central rectangle blocks movement.

The runtime bridge can inject the `lab_*` actions and inspect the exported
runtime observations. These names and success conditions belong to this fixture
only. Generic bridge operations contain no fixture-specific checks.
